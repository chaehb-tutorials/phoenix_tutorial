# Load Timescaledb Extension

## Create a migration
```sh
mix ecto.gen.migration load_timescaledb_extension
```

## Add SQL Query to the migration

> priv/repo/migrations/xxx_load_timescaledb_extension.exs
```elixir
defmodule PhoenixTutorial.Repo.Migrations.LoadTimescaledbExtension do
  use Ecto.Migration
  def change do
    ##---- add this line
    execute("CREATE EXTENSION IF NOT EXISTS timescaledb;")
  end
end
```

## Run the migration
```sh
mix ecto.migrate
```

## (Optional) Confirmation
### Start PostgreSQL Console
> Ubuntu
```sh
sudo -u postgres psql -d phoenix_tutorial
```

> MacOS with Homebrew
```sh
psql -U postgres -d phoenix_tutorial
```

### Check Extensions in PostgreSQL Console
```sh
phoenix_tutorial=# \dx
# if successful loaded, display something like below
timescaledb | x.xx.x  | public     | ...
```
