# Create and Setup Project

##  Phoenix Version
> 1.8.0-rc.3

## Create Project
```sh
mix phx.new phoenix_tutorial --binary-id #--no-install
```

## Change Default Settings
> config/config.exs
```elixir
# ...
# change timestamp_type :utc_datetime to :utc_datetime_usec
  generators: [timestamp_type: :utc_datetime_usec, binary_id: true]

#...
# change esbuild version to lates
config :esbuild,
  version: "0.25.5",

# ...
# change tailwindcss version to lates
config :tailwind,
  version: "4.1.8",

# ...
```
> config/dev.exs
```elixir
# ...
# change database name "phoenix_tutorial_dev" to "phoenix_tutorial"
  database: "phoenix_tutorial",
# ...
```

> mix.exs
```elixir
# change to latest version
# heroicons, dns_cluster
```

## Create Tutorial Database
> in the PostgreSQL console
```sql
CREATE DATABASE phoenix_tutorial WITH
    OWNER = postgres
    ENCODING = 'UTF8'
    LC_COLLATE = 'C.UTF-8'
    LC_CTYPE = 'C.UTF-8'
    BUILTIN_LOCALE = 'C.UTF-8'
    LOCALE_PROVIDER = 'builtin'
    TABLESPACE = pg_default
    CONNECTION LIMIT = -1
    TEMPLATE = template0
    IS_TEMPLATE = False;
```

## If you want to use default CSS Themes
> assets/css/app.css
```css
/*
change
@plugin "../vendor/daisyui" {
    themes: false
}

to
*/
@plugin "../vendor/daisyui" {
    themes:
        light --default,
        dark --prefersdark;
}

/*
    remove or comment out every custom daisyui-theme
@plugin "../vendor/daisyui-theme" {
..
}
*/
```

## Setup
```sh
mix setup
```

## Start
```sh
iex -S mix phx.server
```
